# Roadmap

## v1.0 (Current)

- [x] On-device Whisper transcription
- [x] Global hotkey recording (Push-to-Talk / Toggle)
- [x] Universal text injection via clipboard-paste
- [x] Floating recording widget
- [x] Custom dictionary with developer term presets
- [x] Post-processing pipeline (capitalization, filler removal)
- [x] Local history with search and export
- [x] Usage analytics dashboard
- [x] Model management (download, switch, delete)
- [x] Cloud provider abstraction (OpenAI-compatible)
- [x] Privacy center
- [x] Settings (hotkeys, appearance, injection strategy)
- [x] App-specific profiles (database schema)
- [x] Snippet expansion (database schema)

## v1.1 — Polish

- [ ] Onboarding wizard with permission checks
- [ ] Menu bar tray icon with quick controls
- [ ] Audio start/stop sound effects
- [ ] Silence auto-stop detection
- [ ] Keyboard shortcut recorder widget
- [ ] Drag-to-reposition floating widget
- [ ] Model auto-update checks

## v1.2 — Intelligence

- [ ] Prompt mode: transform dictation into structured AI prompts
- [ ] Context-aware post-processing per app (e.g., code formatting in editors)
- [ ] Smart punctuation using local LLM
- [ ] Voice commands: "new line", "select all", "undo"
- [ ] Real-time streaming transcription (progressive text display)

## v2.0 — Power Features

- [ ] Multi-language dictation with auto-detect
- [ ] Speaker diarization (who said what)
- [ ] Custom fine-tuned Whisper models
- [ ] Integration with clipboard managers (Paste, Raycast)
- [ ] AppleScript/Shortcuts automation support
- [ ] Team shared dictionaries (synced via iCloud)
- [ ] Audio bookmarks and annotations
- [ ] Transcription confidence highlighting
- [ ] Batch file transcription (drag audio files)

## v2.1 — Platform

- [ ] iOS companion app (record on phone, transcribe on Mac)
- [ ] Menu bar-only mode (no dock icon)
- [ ] Touch Bar support (if applicable)
- [ ] Siri Shortcuts integration
- [ ] Spotlight search for history

## Future Exploration

- Linux support (PipeWire audio, X11/Wayland injection)
- Windows support (WASAPI audio, SendInput injection)
- Browser extension for web app injection
- VS Code extension for inline dictation
- Whisper fine-tuning on user's voice
